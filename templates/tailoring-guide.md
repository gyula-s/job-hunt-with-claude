# Tailoring guide

Grows with every application, so later ones only change the title, summary, bullet order and skills. Start it at the end of setup.

## Bases
Versions of the CV for different kinds of role (for example "backend", "full stack"), and which tailored file is the best example of each.

## Summary building blocks
Sentences that are true and have worked, to mix per role.

## Bullet bank
Approved variants of each bullet, per role, with the angle each one suits.

## Skills pool
Skills the user really has, in groups. Plus a never-claim list: skills they don't have, or only at a level that wouldn't survive an interview.

## Cover letter paragraphs
Opening, experience, why-this-company and closing paragraphs that have worked.

## Location and availability lines
How to describe where they live and how they can work.
