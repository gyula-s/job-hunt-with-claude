# Jobgether

- The matches page (`jobgether.com/talent/matches`) needs the user to be signed in.
- **Changing the search filters on the matches page also updates the user's profile preferences.** Jobgether warns about this in a dialog. Cancel, and use the public job search instead, or ask the user first.
- Many listings are reposts of jobs on the employer's own system. Follow through to the original and apply there, and log both sources.
