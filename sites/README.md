# Site notes

One file per job site or application system: what works, what breaks, and what to avoid. Read the matching note before working on a site. Add to it whenever you learn something (a moved button, a hidden file input, a setting that changes the user's profile), with the date. Sites change, so treat an old note as a hint and check.

If a lesson would help everyone, suggest the user contributes it back to the public template repo.
